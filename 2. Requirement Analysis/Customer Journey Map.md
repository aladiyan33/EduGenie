EDUGENIE — CUSTOMER JOURNEY MAP

1. Need identified — Student encounters a difficult concept or large study material.
2. Opens EduGenie — Student reaches the web interface and selects a task.
3. Provides input — Question, topic, passage, or learning topic.
4. Processing — FastAPI validates and routes the request to the appropriate AI module.
5. Receives result — Answer, explanation, summary, quiz, or learning path is displayed.
6. Practices/continues — Quiz answers can be checked; recommendations can be followed.
7. Future relationship — Voice, multilingual, gamification and adaptive learning can extend the workflow.
