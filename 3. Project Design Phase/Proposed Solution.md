EDUGENIE — PROPOSED SOLUTION

EduGenie is a modular web learning assistant with five core capabilities: Q&A, concept explanation, summarization, quiz generation, and learning recommendations.

Modules
main.py — FastAPI routes.
gemini_client.py — shared Gemini access.
qna.py — Q&A.
explanation_module.py — local explanation.
quiz_module.py — quiz generation and validation.
summary_module.py — summarization.
learning_path.py — learning recommendations.

Frontend
HTML/CSS/JavaScript through templates/index.html and static/style.css.

Design goals
Clarity, modularity, reusability, secure configuration, testability, and simple student interaction.
