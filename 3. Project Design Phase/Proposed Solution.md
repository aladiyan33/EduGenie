EDUGENIE — PROPOSED SOLUTION

EduGenie is a modular web learning assistant with five core capabilities: Q&A, concept explanation, summarization, quiz generation, and learning recommendations.

Modules: main.py, gemini_client.py, qna.py, explanation_module.py, quiz_module.py, summary_module.py, learning_path.py.

Frontend: templates/index.html and static/style.css.

Design goals: clarity, modularity, reusability, secure configuration, testability and simple student interaction.
